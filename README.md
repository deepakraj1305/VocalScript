# VoxNote Studio

VoxNote Studio is a browser-based speech-to-text workspace with a clean transcript editor. Speak through your microphone, choose a recognition language, edit the recognized text, and export it as a plain-text file.

## Features

- Microphone speech recognition in supported browsers
- Language selection, including English, Tamil, Hindi, Telugu, Malayalam, Kannada, Bengali, and Marathi
- Editable transcript area
- Word counter and local browser auto-save
- Multiple notes in the same browser
- Copy transcript and download as `.txt`
- Responsive desktop and mobile interface

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`)
- Browser `localStorage`, Clipboard API, and Blob API

## Run Locally

1. Download and extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Run `index.html` using the Live Server extension, or open it in a supported browser.
4. Press **Start listening** and allow microphone access.
5. Speak, edit the transcript, and export it.

Microphone and speech-recognition support varies by browser. A secure context (HTTPS or localhost) is generally required. Some browser implementations may send speech to an online recognition service; do not assume that all recognition happens locally.

## Deploy to Vercel

1. Create a GitHub repository named `VoxNote-Studio`.
2. Upload the extracted project files to the repository root.
3. Go to [Vercel](https://vercel.com/new) and import the repository.
4. Use the default static-site settings and deploy.
5. Test microphone access on the deployed HTTPS URL.

The live demo URL is generated by Vercel after you deploy; this project ZIP does not include an already-hosted demo.

## Push to GitHub with Git

Create an empty repository on GitHub, then run these commands from the extracted folder:

```bash
git init
git add .
git commit -m "Add VoxNote Studio speech transcription app"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/VoxNote-Studio.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

## Limitations

- This is a frontend-only project; there is no backend server or database.
- Recognition depends on the browser's Web Speech API implementation and language availability.
- The app does not upload audio files for transcription.
- Notes are saved in the browser used to create them; they do not automatically sync across devices.
